# web_weather_forecast
Weather App | University Web Development Project

# Описание
Репозиторий содержит код для создания приложения для прогноза погоды для городов России

# Функциональность
Пользователь может:
1. При разрешении определения геопозиции просматривать данные о погоде в текущем местоположении
2. При отклонении разрешения - добавлять погоду с помощью формы (кнопка `Добавить город`)
3. Может выдать разрешение о геопозиции или сменить текущее местоположение с помощью формы (кнопка `Сменить город`)
4. Обновалять данные о погоде, нажав на кнопку `Обновить` или перезугрузив страницу
5. Может добавить минимум 2 дополнительных города
6. Выбирать город из выпадаюшего списка при заполнении формы
7. Просматривать погоду на 5 дней (сегодня + еще 4)

# Получение данных
Данные о погоде получаются с помощью API Open-Meteo (с помощью fetch). Данные о городах России были взяты с [репозитория](https://github.com/arbaev/russia-cities) и находятся в файле data.json

# Макет страницы
1. В HTML файле содержится только базовый каркас страницы и статические элементы
2. Все элементы создаются через DOM API
3. Используются семантические теги

# Макет страницы
Для выполнения были использованы чистые HTML, CSS, JavaScript. Без использования фреймворков. Также с помомощью Google Fonts был добавлен шрифт Outfit.

# Адаптивность
Приложение адаптировано под различные устройства и корректно отображается на ноутбуках, планшетах и телефонах.
